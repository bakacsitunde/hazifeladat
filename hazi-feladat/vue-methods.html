Vue.js Elméleti Témakör: Vue Methods (Metódusok)

A működés leírása

A Vue.js keretrendszerben a metódusok (methods) olyan függvények, amelyek a komponens belső logikáját, üzleti folyamatait és az események lekezelését végzik. Segítségükkel reagálhatunk a felhasználói interakciókra, vagy strukturálhatjuk az ismétlődő kódrészleteket.

  • Eseményvezérlés (Event Handling): A metódusokat leggyakrabban a HTML sablonból hívjuk meg a v-on direktíva vagy annak rövidített változata, a @ szimbólum segítségével (például: @click="szamol").
  • Állapotmódosítás és Reaktivitás: A metódusok közvetlen hozzáféréssel rendelkeznek a komponens reaktív adataihoz. Amikor a függvény módosítja a tárolt változók értékét, a Vue automatikusan frissíti a böngészőben megjelenő HTML felületet.
  • Argumentumok átadása: A sablonból történő meghívás során egyedi paramétereket, vagy akár a natív böngészős esemény objektumot ($event) is átadhatjuk a metódusnak feldolgozásra.

Minta kód és szintaxis (Options API)

Az alábbi példa bemutatja, hogyan deklarálunk egy metódust, amely gombnyomásra növeli a számláló értékét:

<!-- HTML / Sablon rész -->
<div id="app">
    <p>A kattintások száma: {{ szamlalo }}</p>
    <!-- Eseménykezelő összekötése a metódussal -->
    <button @click="novelSzamlalo">Növelés</button>
</div>

<script>
// JavaScript / Vue logika
const app = Vue.createApp({
    data() {
        return {
            szamlalo: 0 // Reaktív állapot
        }
    },
    methods: {
        novelSzamlalo() {
            // A 'this' kulcsszó segítségével módosítjuk a data tartalmát
            this.szamlalo++;
        }
    }
}).mount('#app');
</script>
