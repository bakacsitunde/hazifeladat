Vue.js Elméleti Témakör: Vue Forms (Űrlapkezelés)

A működés leírása

A Vue.js rendkívül leegyszerűsíti a felhasználói adatbevitelt az űrlapokon (input mezők, textareák, checkboxok, legördülő menük). Az űrlapkezelés magja a dinamikus adatkapcsolat létrehozása.

  • Kétirányú adatköttetés (Two-Way Data Binding): A v-model direktíva segítségével az input mező aktuális értéke és a Vue állapotában (data) lévő változó szorosan össze van láncolva. Ha a felhasználó gépel, a változó azonnal frissül; ha a változót kódból írjuk felül, a beviteli mező azonnal felveszi az új értéket.
  • Eseménymódosítók (Event Modifiers): Az űrlapok elküldésekor a böngészők alapértelmezetten újratöltik az oldalt. A Vue-ban a @submit.prevent módosító használatával ez a működés letiltható, így az adatok feldolgozását vagy API-nak való továbbítását teljesen a háttérben végezhetjük el.
  • Sokoldalúság: A v-model intelligensen alkalmazkodik az elem típusához. Megfelelően kezeli a logikai értékeket a jelölőnégyzeteknél (true/false), a string tömböket a többszörös kijelöléseknél, valamint a szöveges beviteleket is.

Minta kód és szintaxis (Options API)

Az alábbi példa bemutatja a kétirányú adatköttetés megvalósítását és a hagyományos űrlap-elküldés letiltását:

<!-- HTML / Sablon rész -->
<div id="app">
    <!-- Megakadályozzuk az oldal újratöltését a .prevent segítségével -->
    <form @submit.prevent="kuldesKezeles">
        <label>Felhasználónév:</label>
        <!-- Kétirányú kötés a v-model direktívával -->
        <input type="text" v-model="felhasznaloNev" placeholder="Írd be a neved...">
        
        <button type="submit">Regisztráció</button>
    </form>
    
    <p>Gépelés közbeni élő előnézet: {{ felhasznaloNev }}</p>
</div>

<script>
// JavaScript / Vue logika
const app = Vue.createApp({
    data() {
        return {
            felhasznaloNev: '' // Ide kötődik be az input értéke
        }
    },
    methods: {
        kuldesKezeles() {
            alert('Sikeres űrlap feldolgozás! Név: ' + this.felhasznaloNev);
        }
    }
}).mount('#app');
</script>
